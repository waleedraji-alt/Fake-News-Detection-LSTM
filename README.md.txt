# Fake News Detection using LSTM

This project uses Deep Learning (LSTM) to classify news articles as **Real** or **Fake**. 

## 🚀 Features
- Text Preprocessing (Tokenization & Padding).
- Deep Learning Model (LSTM).
- Interactive UI using **Gradio**.

## 🛠️ Tech Stack
- Python, TensorFlow, Pandas, Scikit-learn.
- Deployment: Hugging Face Spaces.

## 📊 Dataset
The model was trained on the "Fake and True News Dataset" containing thousands of articles.
